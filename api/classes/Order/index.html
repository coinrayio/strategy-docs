Class: Order

Fluent builder for an order group with multiple entry legs and/or multiple take-profit legs: the full model the backtester supports. Chain legs, then call .submit(). For the common single-market-entry case prefer strategy.long/short. weight is each leg's fraction of the group's qty.

strategy.order("breakout", Side.Long) .limitEntry(close * 0.99, 0.5).limitEntry(close * 0.98, 0.5) .takeProfit(close * 1.02, 0.5).takeProfit(close * 1.05, 0.5) .stopLoss(close * 0.97).qtyPercentEquity(100).submit();

Exit legs take an optional exitId: legs sharing an id form one exit (one-cancels-other) for weight of the position, amendable later with strategy.edit(groupId). Without an id a take profit closes its weight and the stop loss / trailing stop covers whatever remains.
